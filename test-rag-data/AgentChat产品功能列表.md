AgentChat 产品功能列表

==========================
一、对话功能
==========================

1. 多轮对话：支持上下文记忆，可在同一会话中连续追问。
2. 流式输出：对话回复采用 SSE（Server-Sent Events）流式传输，打字机效果。
3. Markdown 渲染：支持代码高亮、表格、列表等 Markdown 格式。
4. 对话管理：可创建多个会话，支持重命名、删除、切换。

==========================
二、Agent 管理
==========================

1. 创建 Agent：自定义名称、头像、欢迎语、系统提示词。
2. 模型选择：每个 Agent 可独立配置使用的 LLM 模型。
3. 工具配置：为 Agent 挂载工具（知识库检索、文生图、技能等）。
4. 知识库绑定：Agent 可绑定多个知识库，启用 RAG 检索增强。
5. 技能扩展：支持加载自定义技能，扩展 Agent 能力。

==========================
三、知识库管理
==========================

1. 创建知识库：支持创建多个独立知识库，按主题分类管理。
2. 文件上传：支持 PDF、Word、Excel、PPT、Markdown、图片、纯文本等格式。
3. 自动向量化：上传后自动解析、切分、向量化，存入 ChromaDB。
4. 状态追踪：文件状态实时显示（进行中、完成、失败）。
5. 文件管理：支持删除、重新上传等操作。

==========================
四、RAG 检索增强
==========================

1. 工具调用模式：LLM 自主决定是否检索知识库，按需调用。
2. 查询重写：对用户问题进行语义改写，提高召回率。
3. 混合检索：支持向量语义检索，可选 Elasticsearch 关键词检索。
4. 重排序：使用 gte-rerank-v2 模型对召回结果重排，提升准确性。
5. 阈值过滤：通过 min_score 过滤低相关度结果，减少噪声。

==========================
五、工具调用
==========================

1. 文生图：调用通义万相模型，根据文字描述生成图片。
2. 知识库检索：检索绑定知识库中的相关内容。
3. 技能工具：Agent 可加载自定义技能作为工具使用。
4. 工具执行可视化：工具调用过程在对话中以事件卡片展示。

==========================
六、记忆系统
==========================

1. 短期记忆：同一会话内的上下文记忆。
2. 长期记忆：跨会话记住用户偏好和历史信息。
3. 记忆管理：可查看和管理已记忆的信息。

==========================
七、用户系统
==========================

1. 用户注册与登录。
2. 多用户隔离：每个用户的数据独立，互不影响。
3. 用户头像与个人信息管理。

==========================
八、系统配置
==========================

1. 多模型配置：支持配置多个 LLM、Embedding、Rerank 模型。
2. 数据库配置：MySQL 业务数据 + ChromaDB 向量数据。
3. 缓存配置：Redis 用于会话和缓存。
4. 对象存储：MinIO 用于文件存储。
5. 环境切换：支持 dev / test / prod 三种环境。
