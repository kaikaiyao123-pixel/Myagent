一句话总结

请求经 main.py → 中间件 → POST /completion 进入 GeneralAgent；它把 MCP / Skill / RAG / OpenAPI / 内置工具都包成 @tool，用 LangGraph create_agent 跑 ReAct 循环，循环里 LLM 决策调工具、工具（尤其是 MCP/Skill）本身又是一个嵌套 ReAct；过程中产生的 token 与工具事件通过 SSE 实时推回前端，流结束后再把历史/摘要/记忆落库。
